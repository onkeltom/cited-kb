# Local tagger weights

`cited.py mine propose` expects `BAAI/bge-small-en-v1.5` in `models/bge-small/`:
`config.json`, `model.safetensors`, and `tokenizer.json`.

The weights are MIT and are not in this repository (about 130 MB). Download them
from Hugging Face into that folder. Search, cards, and briefs work without them.
You tag by hand until the model is there.
